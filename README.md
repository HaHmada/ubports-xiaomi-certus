# Xiaomi Redmi 6/6A
This is a Halium 10 based port for the Xiaomi Redmi 6 and 6A.
To get this booting you *must* be on the *LineageOS 17.1* for your device.

Click the link below to download LineageOS 17.1:

LineageOS 17.1 (certus64): [Link](https://sourceforge.net/projects/wulan17/files/CerTus/Lineage-17.1/lineage-17.1-20211004-UNOFFICIAL-certus64.zip/download)
